## Acceptance example

Start → agent/script producing an issue number → GitHub Issue commented → task consuming comment body. The wait appears without a worker; a signed new comment resumes the original execution once. A restart preserves the wait. Unrelated issues, old comments and duplicates do not advance it. An independent branch can complete while this branch waits; a join waits for both.

When two distinct comments arrive concurrently for one armed activation, exactly one claims it and resumes the instance. Further comments while downstream work runs cause no resumption and are not queued. If the same instance later re-enters the wait, only a newly created qualifying comment can resume that new activation.
