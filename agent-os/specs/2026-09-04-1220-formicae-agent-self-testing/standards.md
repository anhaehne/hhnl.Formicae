# Standards for Formicae Agent Self-Testing

## Applicable Standards

No current repository standard applies to this work.

The standards index currently contains only `database/ef-migrations`. This feature adds no database schema or Entity Framework migration, so that standard is intentionally not included.

Repository-level instructions in `AGENTS.md` still govern implementation, especially scoped changes, preservation of user work, Agent OS usage, Kubernetes as the target runtime, framework-native integration research, version alignment, validation after changes, and reporting test counts in pull request summaries.
